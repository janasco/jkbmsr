# JK BMS Remote Documentation

JK BMS Remote is an independent remote monitoring solution compatible with JK-BMS products. JK BMS Remote is not affiliated with, endorsed by, or sponsored by JK-BMS.

JK BMS Remote provides professional remote monitoring for JK-BMS systems using an ESP32 gateway and JKBMSR Cloud.

Start with the product overview, then follow the gateway setup and wiring guides.

Firmware download, checksum verification, OTA validation, OTA safety, and release notes are documented in the Firmware and Safety sections.

## Important Safety Warning

Battery systems can be dangerous. Incorrect wiring can damage equipment, start a fire, or cause serious injury.

Never power an ESP32 directly from battery pack voltage. Use a properly rated power supply or buck converter.

# Product Overview

JK BMS Remote is an independent remote monitoring solution compatible with JK-BMS products. JK BMS Remote is not affiliated with, endorsed by, or sponsored by JK-BMS.

JK BMS Remote is a remote monitoring system for JK-BMS battery management systems.

An ESP32 gateway connects to the JK-BMS over UART, reads battery data, connects to WiFi, and uploads telemetry to JKBMSR Cloud.

Users can monitor batteries from a web dashboard without Home Assistant, MQTT, VPNs, or port forwarding.

Public firmware artifacts, checksums, and release notes are published separately from the private source repositories.

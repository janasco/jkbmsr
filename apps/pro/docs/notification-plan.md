# Notification Plan

Push notifications are planned after the first mobile MVP.

## Notification Types

- Critical battery alerts.
- High or low cell voltage.
- High temperature.
- Device offline.
- OTA update available.
- OTA update completed or failed.

## Requirements

- Customers must be able to opt in or out.
- Critical alerts should be clearly separated from informational updates.
- Notification preferences should be stored in JKBMSR Cloud.

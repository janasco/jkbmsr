multi-component repository. It is **not a standalone repository**: build tooling,
CI and shared conventions live at the repository root, and paths in this app's
documentation are written relative to this directory.

## What is deliberately NOT in this tree

This is a public source tree. The following are intentionally excluded and must be
supplied locally (or by CI) to build and ship the app. They are git-ignored, and no
copy is kept in this repository's history:

| Excluded | Why | How to supply it |
|---|---|---|
| `android/app/google-services.json` | Firebase/Android project config — contains a project id and an API key | Download from the Firebase console for your own project |
| `android/upload-keystore.jks` | Android release upload key — the upload key can publish updates to real users | Generate with `keytool`, or obtain from the release owner |
| `android/key.properties` | Keystore path, alias and the two passwords | Write locally. The signing policy is documented in the private operations repository. |
| `scripts/.env.local` | `BLE_RELEASE_UPLOAD_SECRET` used by `scripts/publish-release.sh` | Create locally, or export the secret in CI |
| `.env`, `.env.*` | Local secrets. A `.env` here was once committed with a live Polar.sh access token; the file is now vestigial and permanently ignored | Only [`.env.example`](.env.example) is tracked, and it is comments only |
| `build/`, `.dart_tool/`, `android/build/`, `android/.gradle/` | Build output and Gradle caches. Machine-local paths and caches, never source | Regenerated by `flutter pub get` / `flutter build` |

**There is no signing material, Firebase configuration, or API secret anywhere in
this tree, and none is recoverable from it.** Anyone can build a *debug* APK from a
clean clone; producing a publishable, correctly-signed release artifact requires
credentials that are deliberately not distributed.

## Build and test

```sh
flutter pub get
flutter analyze
flutter test
```

`flutter analyze` and `flutter test` are both expected to be clean on a fresh
checkout. No secret or Firebase file is required for either.

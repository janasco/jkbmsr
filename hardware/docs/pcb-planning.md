# PCB Planning

## JKBMSR Mini

- ESP32.
- Bluetooth (BLE) link to JK-BMS — no wired BMS connection required.
- Buck converter input.
- USB-C power and programming.
- Status LEDs.
- Reset and boot buttons.

## JKBMSR Pro

- ESP32.
- RS485.
- CAN.
- Ethernet.
- Isolated power.
- Enclosure.

No PCB files should be created yet. This repository starts with planning documentation.
